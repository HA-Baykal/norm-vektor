## 4. Что осталось на вашей стороне (не обязательно, но полезно)

1. **Яндекс.Вебмастер / Search Console** — отправить sitemap на переобход и добавить URL статьи
   в «Переобход страниц». Кэш CDN (`s-maxage=86400`) новый деплой сбросил, так что 404 больше нет.
2. **Дзен** — RSS уже содержит статью первым item; если лента в Дзене подключена к `/rss-fresh.xml`,
   подтянется сама.
3. Прогнать `npm run check:seo https://www.vektor-komforta.ru` и убедиться, что 311/311.

## 5. Как добавить следующую статью (чтобы не повторилась эта история)

1. Текст — объект в `articleContent` (`src/pages/BlogArticle.tsx`) + карточка в `articles`
   (`src/pages/BlogPage.tsx`) + slug в `blogSlugs` (`vite.config.ts`, fallback).
2. `npm run build` — сам перегенерирует `articlesData.ts`, `sitemap.xml`, `vercel.json`, `_redirects`.
   **Руками эти файлы не править.**
3. Проверить локально: `node scripts/serve-local.mjs` → `node scripts/check-seo.mjs http://localhost:4173`.
4. PR в `main` → **слить его** (именно этого шага не хватило в прошлый раз) → Vercel соберёт прод за ~25 с.
