# Как перенести SEO-изменения к себе на сайт (инструкция для новичков)

Ниже — простой список: **что я создал, что изменил и куда это положить** в твоём проекте.

---

## Часть 1. НОВЫЕ файлы (их у тебя сейчас НЕТ — нужно создать)

| Файл | Куда положить | Зачем нужен |
|---|---|---|
| `useSeo.ts` | в папку `src/utils/` (папка `utils` уже есть — положи внутрь неё) | Это «маленький помощник», который умеет ставить правильные названия вкладки (title) и описание для каждой страницы. Без него остальные правки не заработают. |
| `SEO-AUDIT.md` | в корень проекта (рядом с `package.json`) | Это сам аудит с планом. Для сайта не нужен — просто документация. |
| `api/catalog-data.json` | НЕ загружай руками! | Этот файл создаётся сам при сборке (`npm run build`). |

## Часть 3. Файлы, которые НЕ надо трогать руками

| Файл | Почему |
|---|---|
| `public/sitemap.xml` | Создаётся сам при сборке (`npm run build`) |
| `vercel.json` | Создаётся сам при сборке |
| `dist/` (вся папка) | Создаётся сам при сборке |
| `api/catalog-data.json` | Создаётся сам при сборке |
| `package-lock.json` | Поменялся сам при `npm install` — ничего не делай |

---

## Часть 4. Что сделать ПОСЛЕ переноса файлов (3 шага)

1. Открой терминал (командную строку) в папке проекта.
2. Выполни команду: `npm install` (если ещё не делал) и затем `npm run build`.
3. Загрузи (задеплой) проект на Vercel как обычно.

Во время сборки сайт сам создаст новую карту сайта, `vercel.json` и файл данных — ничего вручную создавать не нужно.

---

## Как скопировать файлы из этой среды

1. Открой нужный файл (например `src/pages/LocalCityPage.tsx`) в просмотрщике.
2. Скопируй всё содержимое (Ctrl+A → Ctrl+C).
3. Открой такой же файл у себя и замени содержимое целиком (Ctrl+A → Ctrl+V).

**Важно:** пути в колонке «Куда положить» — это путь ОТ корня проекта. Например `src/pages/LocalCityPage.tsx` значит: зайди в папку `src`, потом в папку `pages`, там лежит файл `LocalCityPage.tsx`.
