# Как откатить каталог B2B: 155 → 127 карточек (25.08.2026)

Этот документ относится к PR, который объединяет мобильные/промышленные модели по BTU, исправляет правила монтажа и добавляет полные официальные галереи.

Если внедрение не понравилось, порядок действий зависит от того, успели ли вы смержить PR.

---

## 1. Если PR ещё не смержен

1. Откройте PR на GitHub и нажмите **Close** без merge.
2. Ничего на опубликованном сайте не изменится: ветка не попадёт в `main` и не будет задеплоена.
3. Ветку `arena/01a0371d-norm-vektor` можно удалить после закрытия PR или оставить — на сайт она не влияет.

---

## 2. Если PR уже смержен — откат через GitHub

1. Откройте смерженный PR.
2. Нажмите **Revert** — GitHub создаст отдельный PR отката.
3. Смержите PR отката, чтобы вернуть `main` к состоянию до изменения каталога.

Или из терминала:

```bash
git checkout main
git pull
# <sha> — хеш merge-коммита PR
git revert -m 1 <sha>
git push origin main
```

Полный `revert` предпочтительнее ручного отката: он одновременно восстановит удалённые карточки, SEO, старое поведение монтажа, обложки и галереи.

---

## 3. Временный откат деплоя на Vercel

1. Vercel → проект → **Deployments**.
2. Найдите последний успешный деплой до слияния PR.
3. Меню **⋮** → **Instant Rollback** → подтвердите.

> Instant Rollback меняет только опубликованную версию. Код в `main` остаётся прежним, поэтому для постоянного отката всё равно выполните пункт 2.

## 5. Частичный откат

Ручной частичный откат рискован: одни и те же id связаны между каталогом, SEO, галереями, итоговой ценой и сгенерированными файлами. Безопаснее сначала сделать полный revert, затем отдельным PR вернуть только нужную часть.

Если частичный откат всё же необходим:

1. восстановите нужные карточки/варианты одновременно в `src/components/CatalogConditioners.tsx` и `api/seo.js`;
2. синхронизируйте `EXACT_OFFICIAL_PHOTOS_BY_ID` и обложки;
3. проверьте правила монтажа в карточке и сравнении;
4. выполните `npm run build` и `npx tsc --noEmit`;
5. убедитесь, что количества каталога, SEO и sitemap совпадают перед деплоем.
