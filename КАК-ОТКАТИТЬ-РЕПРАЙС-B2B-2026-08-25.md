# Как откатить репрайс B2B + мобильные/промышленные кондиционеры (25.08.2026)

Если внедрение не понравилось — порядок действий зависит от того, успели ли вы смержить PR.

---

## 1. Если PR ещё не смержен

1. Откройте PR на GitHub и просто **закройте его** (Close, без merge).
2. Ничего на сайте не изменится: ветка не попадает в main и не деплоится на Vercel.
3. Ветку `arena/01a036e8-norm-vektor` можно удалить вручную или оставить — на сайт она не влияет.

---

## 2. Если PR уже смержен — откат через кнопку на GitHub

1. Откройте смерженный PR.
2. Нажмите **Revert** (GitHub сам создаст ветку и PR «Revert: <название>»).
3. Смержите PR отката — main вернётся в состояние до репрайса.

Или из терминала:

```bash
git checkout main
git pull
# <sha> — хеш merge-коммита PR (виден в истории: git log --oneline -10)
git revert -m 1 <sha>
git push origin main
```

---

## 3. Быстрый способ — откат деплоя на Vercel (пока задеплоено)

1. Vercel → проект → вкладка **Deployments**.
2. Найдите деплой, который был **до** слияния PR (обычно он помечен как предыдущий successful).
3. Откройте его меню (**⋮**) → **Instant Rollback**.
4. Подтвердите — сайт мгновенно вернётся к предыдущей версии без правок кода.

> Instant Rollback откатывает только опубликованную версию. Код в main останется с репрайсом — при следующем деплое изменения вернутся. Поэтому после Instant Rollback всё равно выполните пункт 2, если хотите убрать изменения из кода навсегда.

## 5. Если раздел «Мобильные» не понравился, а репрайс оставить можно

Не откатывайте весь PR целиком. Частичный откат — вручную (по пункту 4):

- удалите из `src/components/CatalogConditioners.tsx` блок id 754–818 (между маркером `// Мобильные и промышленные (B2B Русклимат + daichi.market), 25.08.2026` и закрывающим `];`);
- удалите те же 65 записей из `api/seo.js`;
- верните фильтру строки `<option value="Мобильный">…` и `<option value="Промышленный">…` (удалить), юнион типа и `api/img-proxy.js` можно оставить безвредными;
- `npm run build` (пересоберёт api/catalog-data.json, dist, sitemap) → коммит → деплой.
