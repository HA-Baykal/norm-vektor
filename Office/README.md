# AI Office

Локальный и веб-офис: директор, агенты, DeepSeek для текста, GenAPI для картинок/видео и сложных задач.

## Запуск

```
pip install -r requirements.txt
python office_app.py
```

Окно или браузер: `http://127.0.0.1:8080`

## Ключи

Скопируйте `config.example.json` → `config.json` рядом с `office_app.py` или заполните в UI:

- **API** — DeepSeek (чат)
- **GitHub / Vercel** — сайт + поле **GenAPI Token**
- **ЮKassa** — shopId и секрет в том же диалоге подключений

Регистрация: email + пароль. Кредиты покупаются тарифами.

## Кредиты

1 ₽ для клиента = 10 кредитов. Картинки ×4 к себестоимости GenAPI, текст ×8 к оценке DeepSeek.

| Тариф | Кредиты | Цена |
|---|---|---|
| Пробный | 1 000 | 99 ₽ |
| Старт | 5 000 | 500 ₽ |
| Бизнес | 20 000 | 1 800 ₽ |
| Профи | 60 000 | 4 800 ₽ |

## Маршрут директора

1. Текст, темы, статьи, код — DeepSeek.
2. Картинка / видео / DeepSeek не ответил — GenAPI, модель по сложности.
3. Списание кредитов после успеха; при ошибке — не списываем.
