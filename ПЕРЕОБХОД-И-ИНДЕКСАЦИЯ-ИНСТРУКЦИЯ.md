# Переобход и индексация: что делает человек после деплоя

Документ для владельца сайта. Всё, что можно сделать кодом, уже сделано
(IndexNow, `llms.txt`, «Короткий ответ», FAQ-разметка). Здесь — шаги в личных
кабинетах: Яндекс.Вебмастер, Google Search Console, Bing Webmaster Tools.

Зачем: Яндекс Нейро и Алиса отвечают по индексу Яндекса, ChatGPT Search и
Copilot — по индексу Bing. Пока страницы не в индексе, ИИ их не цитирует.
Переобход — самый короткий путь.

**Порядок важен:**

1. Код на проде (после мержа PR и деплоя Vercel/Netlify) — иначе статьи уедут
   в переобход со старой, обрезанной версией.
2. IndexNow `--all` — сообщаем поисковикам об обновлении 324 страниц
   (запускает агент: `node scripts/indexnow.mjs --all`).
3. Точечный переобход: Яндекс → Google → Bing.

Ориентиры по времени: Яндекс ~10 минут, Google ~10 минут, Bing ~5 минут.
Лимиты заставляют растянуть работу на 2–3 дня — таблица в конце.

## 1. Яндекс.Вебмастер — webmaster.yandex.ru

### 1.1 Главное зеркало (сделать, если ещё не делали)

Все карты и canonical сайта — на **www**. Значит, главным зеркалом должен быть
`https://www.vektor-komforta.ru`.

1. «Индексирование» → «Переезд сайта»
   (https://webmaster.yandex.ru/site/indexing/mirrors/).
2. В списке зеркал выберите `https://www.vektor-komforta.ru` → «Сохранить».
3. Через несколько дней оно станет главным. Если в списке есть вариант без www
   или с http — не страшно, главное, чтобы главным было www + https.

### 1.2 Переобход страниц — 19 адресов в первый же день

«Индексирование» → «Переобход страниц» (у части аккаунтов: «Инструменты» →
«Переобход страниц»). Вставьте все адреса сразу, по одному в строке:

### 1.3 Мониторинг важных страниц — 20 адресов

«Индексирование» → «Мониторинг важных страниц» (в некоторых аккаунтах
«Отслеживание изменений»). Добавьте: `/`, `/okna`, `/kondicionery`,
`/ventilyaciya`, `/almaznoe-burenie`, `/montazh-okon`, `/montazh-kondicionerov`,
`/servis-kondicionerov`, `/osteklenie-balkonov`, `/baza-znaniy`. Всего можно 20
адресов — инструмент важнее разового переобхода: он сигналит о любом изменении
автоматически.

### 1.4 Карта сайта и Метрика

1. «Индексирование» → «Файлы Sitemap»: проверьте, что
   `https://www.vektor-komforta.ru/sitemap.xml` загружен, обработано ~324 URL,
   и нажмите «Обновить».
2. «Настройки» → «Привязка к Яндекс.Метрике»: добавьте счётчик **110599022**.
3. В «Индексировании» включите тумблер «Обход» напротив счётчика — Вебмастер
   будет обходить страницы, которые реально смотрят люди.

### 1.5 Через 3–14 дней

- «Индексирование» → «Страницы в поиске»: сколько URL в индексе и что исключено.
- «Анализ индексирования страницы»: вставьте `/kondicionery` — должно быть
  «доступна для поиска».
- «Диагностика»: предупреждения по новым страницам.

> Нейро и Алиса отвечают по индексу Яндекса, поэтому переобход — самый короткий
> путь попасть в ИИ-ответы Яндекса.

## 2. Google Search Console — search.google.com/search-console

Свойство — обязательно `https://www.vektor-komforta.ru/` (карта сайта только на
www). Доменное свойство `vektor-komforta.ru` тоже подойдёт.

### 2.1 Карта сайта

«Файлы Sitemap» → в поле «Добавить новую карту сайта» введите `sitemap.xml` →
«Отправить». Статус «Успешно», найдено ~324 страницы.

### 2.2 Запрос индексирования — по 10–12 адресов в сутки

1. Сверху страницы — строка «Проверка URL».
2. Вставьте адрес → дождитесь проверки → «Запросить индексирование».
3. Кнопка гаснет на сутки (лимит ~10–12 адресов в сутки на свойство).

| День | Что отправить |
|---|---|
| 1 | 5 услуг + 4 под-услуги + 3 исправленные статьи = 12 |
| 2 | оставшиеся 7 статей + `/baza-znaniy` |

4. В карточке страницы смотрите блок «Разметка»: должны распознаваться
   `FAQPage`, `Service`, `BreadcrumbList`, у статей — `Article`. Google
   показывает FAQ-сниппеты не всем сайтам, но разметка помогает ИИ-движкам и
   другим поисковикам.
5. **Google Indexing API не использовать** — он принимает только вакансии и
   трансляции, для обычных страниц бесполезен.

### 2.3 Через 3–7 дней

- «Индексирование страниц»: «Просканировано, но не проиндексировано» лечится
  контентом, а не переобходом.
- «Расширенные результаты»: ошибки FAQ и хлебных крошек.

## 3. Bing Webmaster Tools — bing.com/webmasters

Bing здесь ключевой: **ChatGPT Search и Copilot отвечают по индексу Bing**.
Без Bing-индекса сайта в ответах ChatGPT почти нет. В `robots.txt` для
`OAI-SearchBot`, `GPTBot`, `PerplexityBot` стоят явные `Allow` — проверено
скриптом `check-geo.mjs`.

Что уже сделано: сайт добавлен, карта `sitemap.xml` отправлена. Осталось:

### 3.1 Убедиться, что отправлена карта именно www-свойства

1. В шапке выберите свойство `https://www.vektor-komforta.ru`.
2. Слева «Sitemaps» → статус **Success**, «URL discovered» ~324 (обновление до
   48 часов).
3. Если в списке только домен без www — добавьте www-свойство: «Add site» →
   `https://www.vektor-komforta.ru`. Подтверждение по DNS или кнопкой «Import
   from Google Search Console» (в один клик, если GSC подтверждён).

### 3.2 Проверка URL и запрос сканирования (5 главных страниц)

«URL Inspection» → по очереди:

```
https://www.vektor-komforta.ru/
https://www.vektor-komforta.ru/okna
https://www.vektor-komforta.ru/kondicionery
https://www.vektor-komforta.ru/ventilyaciya
https://www.vektor-komforta.ru/almaznoe-burenie
```

Для каждой: статус («Indexed» / «Not indexed») и «Request indexing». В Bing
лимит мягче, чем в Google — десятки адресов в сутки.

### 3.3 URL Submission — 9 главных адресов вручную

«URL Submission» → адреса групп 1–2 (главная, 4 услуги, 4 под-услуги) →
Submit. Там же история отправок и остаток квоты (у новых свойств меньше, у
зрелых — до 10 000 в сутки; IndexNow работает вне квоты).

### 3.4 IndexNow — автоматические уведомления

1. Раздел «IndexNow» в меню (у части аккаунтов «Settings» → «IndexNow»).
2. Ключ привязан к свойству:

   - ключ: `0f5329cd354566f96c0ccb6fdc4a86ac`;
   - файл ключа: `https://www.vektor-komforta.ru/0f5329cd354566f96c0ccb6fdc4a86ac.txt`.

3. После запуска `node scripts/indexnow.mjs --all` в разделе появятся принятые
   уведомления по 324 адресам. Те же уведомления получают Яндекс, Seznam, Naver
   и Yep — один запрос расходится по всем.
4. Дальше это работает само: при каждом обновлении main GitHub Actions
   (`.github/workflows/indexnow.yml`) отправляет уведомления о 15 ключевых
   страницах.

**Один раз включить workflow.** В репозитории лежит готовая заготовка
`deploy/indexnow.workflow.yml` — GitHub видит только файлы внутри
`.github/workflows/`, а автоматике запись в эту папку недоступна. Поэтому:

1. Откройте `deploy/indexnow.workflow.yml` в репозитории на GitHub.
2. «Add file» → «Create new file», в поле имени введите
   `.github/workflows/indexnow.yml`.
3. Вставьте содержимое заготовки и нажмите «Commit changes» (в main).
4. Проверьте: вкладка «Actions» → «IndexNow» → «Run workflow» с режимом `key`.
   Через минуту в логе будет «Итог: принято 15 из 15 URL».

### 3.5 Отчёт AI Performance — замер результата

Отчёт «AI Performance» (цитирование в ChatGPT/Copilot): сколько раз сайт
процитирован, доля среди конкурентов, по каким запросам ИИ его нашёл. Смотреть
через 2–4 недели после индексации — это первое место, где видно результат
«ИИ рекомендует Вектор Комфорта».

### 3.6 Ещё две проверки

- «Site Explorer» — сколько URL Bing знает о сайте.
- «SEO Reports» и «Site Scan» — прогнать разово, посмотреть ошибки новых
  страниц; через 1–3 дня проверить в самом Bing `site:vektor-komforta.ru`.

## Что НЕ отправлять на переобход

Адреса с фильтрами (`/kondicionery?type=Мобильный` и подобные) закрыты
`noindex` намеренно — это страницы-дубли. В Вебмастере они будут отмечены как
«закрыта от индексации» — это норма, а не ошибка.

## Как понять, что сработало

| Что | Где смотреть | Когда |
|---|---|---|
| Bing знает страницы | `site:vektor-komforta.ru` в Bing | 1–3 дня |
| Яндекс переобошёл | Вебмастер → «Переобход страниц» → «Робот обошёл» | 3–14 дней |
| Google проиндексировал | GSC → «Проверка URL» | 1–4 недели |
| ChatGPT цитирует сайт | Bing → «AI Performance» | 2–4 недели |
| Яндекс Нейро цитирует | спросить в Нейро/Алисе «окна в Иркутске» | 1–3 месяца |
| Люди приходят из ИИ | Метрика 110599022 → сегмент по `ai_source` | 1 месяц |

Ориентир: первые цитирования в ИИ-ответах обычно появляются на 2–4 месяц —
это норма, а не признак ошибки. Главное — чтобы контент был полным (сделано) и
поисковики о нём узнали (этот чек-лист).
