# Разбор правок по строчкам: БЫЛО → СТАЛО (для новичков)

Это пошаговая инструкция: для каждого файла показано **где именно** менять,
**что убрать** (красное) и **что вставить** (зелёное). Делай по порядку — ничего не сломается.

> Как читать:
> 🔴 `БЫЛО` — строчка, которая сейчас у тебя есть (её удаляем/заменяем)
> 🟢 `СТАЛО` — строчка, которую вставляем вместо неё
> ➕ `ДОБАВИТЬ` — просто вставить новый кусок (ничего не удаляя)

## ШАГ 0. Сначала создай ОДИН новый файл (без него всё остальное не заработает)

**Файл:** `src/utils/useSeo.ts`
**Где:** папка `src` → папка `utils` → создай новый файл с именем `useSeo.ts`
(папка `utils` уже есть, внутри неё лежит файл `cn.ts` — клади рядом).

Открой этот файл у себя (создай пустой) и **вставь в него целиком** этот код:

```ts
import { useEffect } from "react";

const DEFAULT_TITLE = "Пластиковые окна, кондиционеры и вентиляция в Иркутске — Вектор Комфорта";

function setMeta(nameOrProperty: string, content: string, isProperty = false) {
  const attr = isProperty ? "property" : "name";
  let meta = document.querySelector(`meta[${attr}="${nameOrProperty}"]`) as HTMLMetaElement | null;
  if (!meta) {
    meta = document.createElement("meta");
    meta.setAttribute(attr, nameOrProperty);
    document.head.appendChild(meta);
  }
  meta.content = content;
}

export function useSeo(title: string, description: string) {
  useEffect(() => {
    document.title = title;
    setMeta("description", description);
    setMeta("og:title", title, true);
    setMeta("og:description", description, true);
    setMeta("og:url", window.location.href, true);
    setMeta("og:type", "website", true);

    return () => {
      document.title = DEFAULT_TITLE;
    };
  }, [title, description]);
}
```

Это «помощник»: он умеет ставить название вкладки и описание страницы.
Сохрани файл. Дальше идём по остальным файлам.
